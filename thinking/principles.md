# 个人原则库(已升格的结论,L1 级记忆)

> 只有 thread 迭代收敛后才能进入本文件。每条注明来源 thread。

## 决策
- 个体决策用 Kelly / 非遍历性框架,不用期望值最大化;组合式低成本并行测试优于单点押注。(来源:VC 幂律解构)
- 保留股权 + 时间自主 + 低公开暴露 > 最大化账面净值。(来源:IPO vs bootstrap 分析)
- 跨市场 founder-fit 应按信任来源判断：经验型杠杆依赖履历与文化直觉，系统型杠杆依赖可验证结果；跨文化选位优先“离机器近、离文化远”。(来源:[两种杠杆判别法](两种杠杆判别法_离机器近离文化远.md))
- MVP / 选品先用[工作流候选方向生成器](工作流候选方向生成器.md)从真实工作生成候选，再看现行决策一页纸：三红线 + 反脆弱九门。(来源:[决策原则_红线与MVP反脆弱九门](../projects/careerradar/决策原则_红线与MVP反脆弱九门.md))

## 资产
- 资产三分:Class A 不可回填 / B 折旧 / C 燃料。
- CareerRadar：结果数据（Outcome）为 Class A，必须 day-one 收集；可触达权（Email 等）为不可砍的底层管道，与 Outcome 并列守住（红线3）。(来源:决策原则九门)

## 商业
- 商机判断分三层：①工作流候选方向生成器从身份、真实 Workflow、Distribution 与 Friction 产生候选；跨市场迁移、数据异常、技术/监管/渠道变化只作为补充来源；②六因子负责横向排序；③三红线 / 五关 / 九门负责否决、验证时序与 MVP 放行。高分不等于可以动手，真实支付未验证时只能标记 `待验`。(来源:[工作流候选方向生成器](工作流候选方向生成器.md) + 商机质量六因子讨论 2026-07-31)
- 商机质量采用非补偿模型：`基础商机质量 = GM(结构性供需缺口, 变现强度, 分发可复制性, 交付可复制性, 资产复利性, Founder Fit)`；`最终商机质量 = 基础商机质量 × 控制权系数`。六项各评 0–5 分，任一项 ≤1 直接淘汰，避免用其他长板掩盖致命短板；`GM` 为几何平均数。
  - 结构性供需缺口：缺口来自地理、技术、渠道、监管、成本、信息差或工作流跃迁，且能解释「为什么现在仍空着」。
  - 变现强度：客单价 × 购买频率 × 痛点紧迫度 × 预算确定性 × 毛利，不把口头意愿计作支付证据。
  - 分发可复制性：第 100 个用户来自可重复机制；必须给出具体渠道、流量规模、CAC 与渠道所有权。
  - 交付可复制性：第 1 单可人工，第 10 单形成 SOP，第 100 单主要由软件、数据或自动化交付；订单增长时单位交付成本与质量波动下降。
  - 资产复利性：每单至少沉淀内容、数据、名单、品牌、关系、代码或决策规则之一。
  - Founder Fit：能力不对称、低能量状态可持续、自主控制、低情绪劳动、低团队依赖，并兼容家庭不可牺牲项。
  - 控制权系数：核心域名、支付、数据、名单均自有为 1.0；存在可替代第三方依赖为 0.7；单一平台掌握获客或交付命脉为 0，直接否决。(来源:商机质量六因子讨论 2026-07-31)

- 决策链方向:渠道 → CAC → 可行价格带 → 变现方式 → 产品形态;新方向的检验顺序为 分发 → 变现 → 产品,产品是被推导出来的,不是被想出来的。(来源:高频验证与渠道所有权 迭代3)

- 方向 = 三交集:①不对称领域 ∩ ②低成本分发场域 ∩ ③场域内可观测痛点(从搜索词/社区/回信读)。找方向从分发场开始,不从功能开始。分发场有两个来源,后者优先:
  ① 外部租用场:搜索场 / 平台 / 已建的关键词矩阵与邮件列表——需支付租金
  ② 自身温层:我天然身处的人群——分发权无需租用,且同时自带痛点直觉、可信度与语言语境。自身痛点不是"缺分发"的选项,而是 分发场∩痛点 重合的特例
  在选定的场内读取需求信号(长尾词、社区提问、订阅者回信、自身一手体验),再用能力组合不对称做最后否决:"我撤出后谁能 3 个月内接手做到同等水平",答得出具体人选即砍掉。
  自身温层的两个独立缺陷(与分发无关,须单独验证):规模不可知(查商业意图词搜索量、是否已有人付费)、支付意愿不等价(找 5 个同温层的人要求预付,不问意愿)。
  已知温层均以"同行"为服务对象,须把"天花板低、对方会自己做"计入单位经济。
  (来源:高频验证与渠道所有权 迭代3 + 温层视角修正 2026-07-29)

- 机会筛选问"如果逻辑显而易见,为什么它现在还空着",答案必须具体。合法答案:执行壁垒 / 无聊低地位 / 对大玩家规模太小 / 时间窗口 / 跨市场信息差 / 耐心壁垒。其中"规模太小"与"耐心壁垒"不依赖比别人聪明,是个人创业者最可靠的两种优势。答案若是"大家都没想到",几乎总是错的。(来源:不确定性与超额利润之辨 2026-07-28)

- 第 100 个用户从哪来:该问题在建造前回答,检验的是"可重复机制"而非冷启动。第 1-100 个来自事件(熟人、Product Hunt、Reddit),不可重复;第 100 个必须来自机制。合格答案必须含具体数字,给不出数字即未验证。第 1000 个用户检验单位经济是否成立。(来源:高频验证与渠道所有权 迭代3)

- 创始人价值正在 AI 时代重新分配:写 Prompt / 写代码 / 写文章不一定最值钱;更值钱的是定义市场 / 定义数据结构 / 定义 Agent Workflow / 定义产品边界——这些决定 AI 该执行什么。(来源:2026-07-29 讨论)

- 内容 / pSEO 型飞轮启动靠快变量,不靠慢变量:飞轮静止时,单靠 SEO(慢变量)几乎推不动;必须先用一次"爆破"(快变量,如集中曝光、外链、社区引爆)注入初始动能与域名权重(Domain Authority),飞轮转起来后慢变量才能接管增长。只打磨产品、只铺慢速 SEO 而没有爆破启动,是常见误区。(来源:2026-07-29 讨论)

## 执行
- 执行力情绪依赖 → 一切靠预承诺规则与系统,不靠意志力。
