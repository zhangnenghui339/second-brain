# 六门→九门设计对照（历史稿）

> **已落地。** 现行执行文件：[`决策原则_红线与MVP反脆弱九门.md`](../projects/careerradar/决策原则_红线与MVP反脆弱九门.md)。  
> 本文仅保留设计过程中的号位搬迁记忆，不再作为执行依据。

## 最终落地的九门（速记）

1. 问题从自己来  
2. 视角够偏  
3. 趋势窗口打开  
4. 新能力刚可用  
5. 市场筛选·上线即收费（可小额买量测付钱）  
6. 自有分发·低获客可复制（长期不能靠买量续命）  
7. 两周一人搞定  
8. 零平台依赖  
9. 停下仍有复利  

## 旧六门 → 九门搬迁

| 旧六门 | 九门落位 |
|---|---|
| 1 他人已验证 | 门3 趋势窗口 + 门4 新能力 |
| 2 先愿付费 | 门5 |
| 3 零平台依赖 | 门8 |
| 4 资产秒交付 | 门7 + 红线2 |
| 5 沉淀复利 | 门9 |
| 6 低获客 / 禁广告 | 门6（测付费买量见门5） |
| （新） | 门1 自己的问题 / 门2 视角够偏 |
