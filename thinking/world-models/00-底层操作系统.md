# Layer 0：底层操作系统

> **组合命题：** 世界既不是确定的，也不是线性的。先把判断表达为概率，再把事件放回反馈回路、存量、延迟和非线性结构中。

## 模型 01：概率世界观（Probabilistic Worldview）

### 核心命题

世界不是“成功 / 失败、好 / 坏、对 / 错”的二元系统，而是会随新证据更新的概率分布。

### 四个机制

1. **Bayesian Updating：** 先验 + 新证据 → 后验；证据改变多少，判断就改变多少。
2. **Expected Value：** `成功概率 × 收益 - 失败概率 × 成本`，判断值不值得做，而非会不会成功。
3. **Asymmetry：** 优先选择下行有限、上行可放大的机会。
4. **Calibration：** 记录概率预测并复盘，让“70%”长期接近真实 70%。

### 适用场景

- 新项目、合作方、定价、招聘、关系判断等信息不完全决策；
- 一次失败后想全盘否定方向；
- 焦虑触发后把一种可能性当成确定事实；
- 需要决定加注、继续验证还是停止。

### 常见误用

- **伪精确：** 没有依据也给出 63% 之类数字；数字必须绑定证据和更新条件。
- **只算期望值，不看毁灭风险：** 正期望不等于可下注；不可承受的下行先否决。
- **把一次采样当总体分布：** 小样本只能改变概率，不能直接宣判。
- **永远不决策：** 概率不是拖延工具；达到行动阈值就行动。

### 调用模板

```text
当前判断：X 的成功概率约为 __%。
证据：支持 __；反对 __；未知 __。
下行：最坏损失 __，是否可承受？
上行：最好结果 __，是否可放大？
行动阈值：概率达到/低于 __% 时加注/退出。
下一条高价值证据：__。
```

### 焦虑校准协议

```text
触发事件
→ 列出至少 3 种解释及概率
→ 判断是否有足够新证据
→ 没有证据则不更新结论
→ 设置信息获取节点和到期动作
```

## 模型 02：系统思维（Systems Thinking）

### 核心命题

行为嵌入在结构里；结果会反过来改变原因。长期轨迹主要由反馈回路决定，而非单次行为质量。

### 四个要素

| 要素 | 问题 |
|---|---|
| **反馈回路** | 结果会不会反过来强化或抑制原因？ |
| **Stock & Flow** | 什么在积累？什么在流入、流出？ |
| **Delay** | 行动到结果之间延迟多久？ |
| **Non-linearity** | 输入增加一倍，结果是否仍只增加一倍？ |

### 两类回路

- **增强回路：** 成功产生更多成功，或失败产生更多失败；复利与焦虑螺旋都属于此类。
- **调节回路：** 系统把结果拉回某个水平；容量、注意力、质量下降和渠道饱和形成天花板。

### 适用场景

- 同类问题不断复发，单点修复无效；
- 越努力越焦虑、越控制越失控；
- 内容、产品、关系或组织的反馈有明显延迟；
- 需要寻找高杠杆干预点。

### 常见误用

- **把复杂图当洞见：** 回路图必须导向可改变的杠杆点。
- **过度分析：** 找不到可验证干预时，应缩小系统边界。
- **忽略延迟：** 在系统仍运行时误判失败并频繁换策略。
- **只画增强回路：** 不寻找限制增长的调节回路。

### 系统诊断模板

```text
症状：__。
存量：正在积累/消耗的是 __。
流量：主要流入 __；主要流出 __。
增强回路：A → B → C → A。
调节回路：增长触发 __，它反向压制 __。
关键延迟：__ 天/周/月。
杠杆点：改变 __，能以最小动作改变整个回路。
验证实验：在 __ 时间内观察 __ 指标。
```

## 两个模型如何串联

```text
概率世界观：我对结果有多大把握？
→ 系统思维：什么结构会让这个概率随时间上升或下降？
→ 最小干预：在哪个杠杆点做低成本实验？
→ 新证据：更新概率与回路判断。
```

只用概率会忽略路径依赖；只用系统思维会产生漂亮但无法验证的叙事。二者必须通过真实数据闭环。
