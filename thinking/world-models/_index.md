# 世界观操作系统：思维模型路由

> **定位：** 这不是一组需要全部同时使用的理论，而是面对不确定世界时的模型选择器。先识别问题结构，再调用最少模型；模型之间交叉验证，不把任何模型当成现实本身。

## 当前结论

顶尖思考者与普通人的差距，不在于拥有更多模型，而在于：

1. 知道自己正在使用哪个模型；
2. 知道它解释了什么、遗漏了什么；
3. 能在新证据出现时切换模型；
4. 知道**地图不是领土**，模型冲突时回到事实、行为与结果。

默认调用纪律：**1 个主模型 + 1 个反证模型；复杂问题最多再加 1 个时间模型。** 不允许把 14 个模型全部堆进一次分析。

## 二、问题路由

| 问题信号 | 主模型 | 反证/辅助模型 | 典型问题 |
|---|---|---|---|
| 信息不足、结果不确定、焦虑跳结论 | **概率世界观** | 乔哈里窗 / 二阶思维 | “当前证据支持多少概率？” |
| 同类问题反复出现、越努力越糟、结果有延迟 | **系统思维** | 激励机制 / 时间折现 | “哪个回路在自我强化？” |
| 合作、谈判、渠道、竞争、权力变化 | **博弈论** | 信息不对称 / 激励机制 | “这是单次还是重复博弈？” |
| 对方嘴上支持但行为不动 | **激励机制** | 博弈论 | “实际收益、成本和惩罚是什么？” |
| 价值无法被理解、双方估值不一致 | **信息不对称** | 心理账户 | “对方缺哪条信息才无法估值？” |
| 不敢分享、害怕失去关系或资源 | **稀缺/丰盛** | 机会成本 / 博弈论 | “真正稀缺的是信息，还是信任背书？” |
| 执行阻力、角色转型、自我否定 | **身份认同** | 概率世界观 / 激励机制 | “哪个隐性身份规则正在执行？” |
| 舍不得退出、付出后期待回报 | **心理账户** | 机会成本 | “如果今天第一次遇见，我还会投入吗？” |
| 意图与外界反馈持续错位 | **乔哈里窗** | 信息不对称 / 身份认同 | “别人看见了什么，而我没看见？” |
| 问题被行业惯例、竞品答案锁死 | **第一性原理** | 系统思维 | “不可再分的事实是什么？” |
| 眼前合理、长期可能恶化 | **二阶思维** | 系统思维 / 复利 | “行动与不行动各自会改变什么？” |
| 多方向竞争时间、资金、注意力 | **机会成本** | 复利 / 时间折现 | “选择 A 等于放弃哪个 B？” |
| 判断长期事业与资产 | **复利** | 时间折现 / 系统思维 | “停止投入后还留下什么？” |
| 明知长期更优却持续选短期 | **时间折现** | 身份认同 / 激励机制 | “如何给长期动作建立即时反馈？” |

## 三、标准调用协议

AI 或本人使用模型时，按以下顺序输出：

```text
1. 决策对象：到底在判断什么？
2. 时间尺度：今天 / 90 天 / 3 年？
3. 事实边界：已知事实、推断、未知分别是什么？
4. 主模型：为什么它最匹配问题结构？
5. 反证模型：主模型可能遗漏什么？
6. 推演：一阶结果、反馈回路、二阶后果、机会成本。
7. 决策：行动 / 小实验 / 等待信息 / 退出。
8. 更新条件：哪条新证据出现时必须改判？
```

建议固定开头：

```text
主模型：X
辅助模型：Y
选择原因：一句话说明问题结构
```

## 四、模型冲突时的裁决

| 冲突 | 裁决规则 |
|---|---|
| 概率判断 vs 身份信念 | 身份不能替代证据；用行为证据更新身份，不用身份筛选证据。 |
| 第一性原理 vs 系统思维 | 第一性原理拆事实，系统思维看事实之间的回路；先拆再连。 |
| 稀缺性 vs 丰盛性 | 时间、注意力、信任背书按稀缺管理；信息、普通连接、公开方法按可复利性判断。 |
| 激励机制 vs 道德评价 | 先解释结构，再评价责任；解释行为不等于为行为免责。 |
| 复利 vs 机会成本 | 有复利不等于值得投入；比较各候选的复利斜率、控制权和中断风险。 |
| 长期价值 vs 当下执行 | 用时间折现模型设计即时反馈，不靠意志力硬扛。 |

## 五、边界：地图不是领土

- 模型是压缩现实的工具，不是现实本身。
- 模型只能生成假设，不能替代事实核查、真实支付、行为数据和 Outcome。
- 对人的模型只能描述“某人在某情境下的行为概率”，不能把人永久归类。
- 同一个结果可能由多个回路共同造成；不要追求唯一解释。
- 当模型输出与持续观测冲突时，**改模型，不改事实。**
