# Layer 4：复利与时间

> **组合命题：** 长期优势来自可持续的正向回路，但大脑会系统性高估当下、低估未来。需要同时设计资产复利与即时反馈。

## 模型 13：复利（Compounding）

### 核心命题

复利不只是金融增长，而是所有“产出能够变成下一轮投入”的系统结构。

```text
本轮行动
→ 留下资产
→ 降低下一轮成本 / 提高成功率
→ 产生更多资产
```

### 复利四变量

| 变量 | 核心问题 |
|---|---|
| **Base** | 起始资产和初始优势是什么？ |
| **Rate** | 每轮净增长率是多少？ |
| **Duration** | 能否持续足够长时间？ |
| **Continuity** | 中断、平台风险或健康耗散会不会切断回路？ |

### 可复利资产

- 可复用代码、数据结构、Agent Workflow；
- SEO 权威、内容库、可持续入口；
- Email、直接关系与可重复触达权；
- Behavior / Outcome 数据；
- 信誉、判断力、合作网络；
- 能提高下一次学习和验证效率的方法论。

### Stop Test

> **如果今天停止主动投入，是否仍留下流量、数据、用户关系、代码模块、信誉或收入？**

停止后什么都不剩，通常是劳动收入或项目输出，不是复利资产。

### 复利的天敌

1. **频繁中断：** 每次换方向都重置 Base。
2. **不可控平台：** 资产沉淀在无法迁移的平台上。
3. **负向回路：** 规模增长同时放大客服、质量和情绪耗散。
4. **伪资产：** 数量增加，但不能降低未来成本或提高成功率。
5. **过早优化：** 还没有正回路就优化增长率。

### 调用问题

- 这次行动会留下什么？
- 留下的资产能否迁移到下一个项目？
- 它提高增长率，还是只增加一次性产出？
- 哪个调节回路会限制复利？
- 中断一次会损失多少积累？

## 模型 14：时间折现（Temporal Discounting）

### 核心命题

人会系统性高估确定、具体、即时的收益，低估抽象、不确定、延迟的未来价值。

### 三个来源

1. **生存偏好：** 大脑为活过今天设计，不为长期复利设计。
2. **具体性差异：** 当下奖励可感知，未来价值只是抽象数字。
3. **不确定性折价：** 时间越远，风险越多，大脑自动追加折扣。

### 高折现与低折现

| 高折现率 | 低折现率 |
|---|---|
| 优先即时确定回报 | 能为长期高价值承受合理延迟 |
| 频繁换方向、追热点 | 维护连续回路与资产积累 |
| 用情绪判断进度 | 用里程碑和领先指标判断 |
| 把延迟误判为无效 | 区分延迟、失败和数据不足 |

低折现率不等于无限等待。长期选择仍需设置验证节点、Kill Criteria 与最大可承受损失。

### 绕过机制：给长期动作建立即时奖励

```text
长期目标
→ 拆成可在 1–7 天完成的资产动作
→ 每次动作生成可见证据
→ 用领先指标提供即时反馈
→ 定期评估是否仍在正确回路
```

即时反馈可以是：完成一次真实触达、形成一个可复用模块、获得一个付费信号、沉淀一条 Outcome 数据，而不是只用虚荣指标制造多巴胺。

### 调用模板

```text
未来价值：__。
当前牺牲：__。
不确定性来源：__。
验证节点：__ 日期检查 __ 指标。
最大等待/亏损：__。
本周可获得的即时资产证据：__。
达到什么条件继续、加注或停止：__。
```

### 常见误用

- 用“长期主义”合理化没有反馈的方向；
- 为延迟收益承受不可逆下行；
- 只奖励完成任务，不奖励形成资产与有效证据；
- 把短期现金流一概视为低级，忽略它对生存与选择权的价值。

## 两模型组合协议

```text
复利模型：什么资产会让未来更容易？
→ 时间折现：为什么今天不愿意做？
→ 激励设计：如何让长期动作获得即时、真实、可见的反馈？
→ 风险控制：设置验证节点、Kill Criteria 和最大下行。
```

最终目标不是牺牲现在换未来，而是建立一个：**当下可以持续、长期能够增值、任何时候都不会因单次失败被摧毁的系统。**
