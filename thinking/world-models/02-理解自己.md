# Layer 2：理解自己

> **组合命题：** 很多“执行力问题”不是能力不足，而是身份规则、心理账本和认知盲区在自动执行。先看见系统，再决定要不要改变。

## 模型 07：身份认同（Identity-Based Behavior）

### 核心命题

长期行为主要由身份驱动，而非目标驱动。人会持续做“与我一致”的事，并回避威胁自我叙事的证据与行动。

### 三层身份

| 层级 | 示例 | 稳定性 |
|---|---|---|
| **结果层** | “我是一个成功的人” | 最脆弱，外部结果一波动就受损 |
| **行为层** | “我是一个持续触达客户的人” | 较稳定，以行为密度而非成交定义 |
| **价值观层** | “我是一个持续构建系统的人” | 最稳定，可跨项目和角色迁移 |

### 六类错误

1. **描述变规定：** “过去不擅长”被升级成“未来不应该做”。
2. **粒度过粗：** 一次局部失败污染整个自我评价。
3. **单一身份：** 把全部稳定性押在职业、关系或单个项目上。
4. **防御性身份：** “我不依赖别人”既提供保护，也切断连接。
5. **顿悟幻觉：** 身份靠行为证据积累，不靠宣言切换。
6. **角色混淆：** 工作角色变化被误解为核心自我消失。

### 身份更新协议

```text
触发阻力：我为什么“不像我”地抗拒这个动作？
→ 隐性规则：做这件事意味着我是怎样的人？
→ 事实检查：这是过去证据，还是未来判决？
→ 重写粒度：把结果身份改为行为/价值身份。
→ 最小证据：设计一个足以支持新身份的微小行为。
→ 连续采样：积累证据，而非要求一次顿悟。
```

### 调用问题

- 哪个身份正在保护我？它同时切断了什么？
- 如果去掉职业、项目和他人评价，我仍认可的价值身份是什么？
- 当前阻力来自真实成本，还是来自身份不一致惩罚？
- 能否把“我不擅长 X”改写为“我正在用 Y 行为学习 X”？

## 模型 08：心理账户（Mental Accounting）

### 核心命题

人会把客观上等价的资源放进不同心理账户，并赋予不同估值。账户标签会扭曲退出、交换和风险判断。

### 三个高频场景

#### 1. 付出与接收估值不对称

付出者经历完整成本，接收者只看到结果；因此“我付出很多”不会自动转化为对方相同额度的心理债务。

#### 2. 沉没成本

过去投入无法通过继续投入收回。决策只应比较：**从今天开始，新增投入的未来收益与替代方案。**

#### 3. 账户重构

谈判中，同一价格可以被归类为成本、保险、增长投资或机会成本。重构账户应帮助对方看见真实价值，不应伪造事实。

### 两条预承诺规则

```text
退出校准：如果今天第一次遇见这个人/项目，我还会选择投入吗？
付出校准：如果对方完全不回报，我还愿意给吗？
```

若第二问为否：不做，或在事前明确交换条件；不要把未表达的期待记成对方债务。

### 常见误用

- 把忠诚与继续追加沉没成本绑定；
- 用“都做这么久了”代替未来价值判断；
- 把自愿付出记入隐性债务账户；
- 只设计对方的心理账户，不审查自己的账本。

## 模型 09：乔哈里窗（Johari Window）

### 核心命题

自我认知由开放区、隐藏区、盲区和未知区构成。影响行动最大的往往不是已知缺点，而是自己看不见、别人能感知的盲区。

| 象限 | 自己知道 | 他人知道 | 操作 |
|---|---|---|---|
| 开放区 | 是 | 是 | 保持信息一致 |
| 隐藏区 | 是 | 否 | 选择性 Self-disclosure |
| 盲区 | 否 | 是 | 请求具体行为反馈 |
| 未知区 | 否 | 否 | 通过新情境与实验探索 |

扩大开放区有两条路径：**自我披露**与**接收反馈**。只披露不反馈是单向表演；只反馈不披露是防御性透明。

### 获取盲区数据

不要问：

> “我哪里做得好？”

改问：

> “我在哪个具体时刻，让你觉得难以靠近、难以合作或有压力？”

操作条件：

1. 只选 1–2 个可信且利益冲突低的人；
2. 明确需要直接观察，不需要安慰；
3. 要具体行为与时刻，不接受人格标签；
4. 反馈是数据点，不是终审判决；
5. 与更多事实交叉验证后再更新判断。

### 常见误用

- 向不安全的人过度披露；
- 把单个人的偏好当客观盲区；
- 请求反馈只是为了获得认可；
- 发现盲区后立刻自我否定，而不是调整行为与意图的对齐。

## 三模型组合协议

```text
身份认同：哪个隐性规则正在驱动我？
→ 心理账户：我如何给投入、关系和退出贴标签？
→ 乔哈里窗：外界实际接收到什么信号？
→ 最小行为实验：改一个可观察动作，收集反馈并更新。
```
