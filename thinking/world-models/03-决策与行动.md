# Layer 3：决策与行动

> **组合命题：** 先把问题拆回不可再分的事实，再推演行动如何改变未来，最后把被放弃的最佳替代方案计入成本。

## 模型 10：第一性原理（First Principles）

### 核心命题

把问题分解到不可再分的事实、约束和目标，然后从基础重新构建答案，而不是从惯例、竞品或类比直接复制结论。

### 拆解顺序

```text
目标：真正要优化什么？
→ 事实：哪些可以被直接验证？
→ 约束：哪些不可改变，哪些只是历史惯例？
→ 假设：哪些结论依赖未经验证的前提？
→ 重构：如果从零开始，最小可行结构是什么？
→ 实验：哪一步能最快证伪核心假设？
```

### 适用场景

- 行业都这么做，但结果持续不理想；
- 解决方案先于问题出现；
- 技术、平台或成本结构已经改变，旧类比可能失效；
- 需要缩小 MVP，找到不可缺的核心。

### 常见误用

- 把“我不同意行业共识”冒充第一性原理；
- 忽略人性、法律、渠道等真实约束；
- 反复拆解却不进入验证；
- 把事实、解释和偏好混在一起。

### 调用问题

- 不借用现有产品名，这个任务的基本事实是什么？
- 哪个限制是物理/制度事实，哪个只是流程惯例？
- 用户真正购买的是功能，还是结果？
- 哪条假设一旦错误，整个方案就不成立？

## 模型 11：二阶思维（Second-Order Thinking）

### 核心命题

一阶思维看直接结果；二阶及以上思维看结果如何改变行为、能力、资源分布和未来选择集。**不行动也是输入，不是静止。**

### 四阶推演

| 阶数 | 问题 |
|---|---|
| 一阶 | 这个动作立刻带来什么？ |
| 二阶 | 直接结果会改变谁的行为与激励？ |
| 三阶 | 新行为会形成什么反馈回路与路径依赖？ |
| 四阶 | 长期会改变我的能力、身份、信誉和机会分布吗？ |

典型错误是把世界想象成静态：我不行动，机会会原地等待。现实中，参与或缺席都会改变未来资源分布；等待可能降低能力、可见度和行动信心，形成自我强化的萎缩回路。

### 为什么思维链在一阶终止

1. **即时惩罚 > 延迟收益：** 被质疑是即时的，能力增长是延迟的。
2. **反事实成本高：** 未来状态难验证，大脑默认悲观折价。
3. **道德合理化：** “准备好再做”常被包装成谨慎与负责。
4. **身份防御：** 深推演可能威胁现有自我叙事，大脑主动结案。

### 调用模板

```text
行动 A：
一阶 __；二阶 __；三阶回路 __；四阶能力/机会变化 __。

不行动：
一阶 __；二阶 __；三阶回路 __；四阶能力/机会变化 __。

哪个后果可逆？哪个后果一旦发生无法回填？
```

### 常见误用

- 无限推演，把不确定性伪装成深度；
- 只推演行动风险，不推演不行动风险；
- 给远期后果极大权重，却没有证据链；
- 用复杂叙事绕过当前必须验证的事实。

## 模型 12：机会成本（Opportunity Cost）

### 核心命题

真正的成本不是已经花了多少，而是当前选择所放弃的**最佳可行替代方案**。

### 四类机会成本

- **时间：** 这 100 小时不能再投入哪个更高价值回路？
- **资本：** 资金是否失去流动性、选择权或下行保护？
- **注意力：** 多项目切换是否破坏深度工作与反馈闭环？
- **身份与信誉：** 这个承诺是否锁定未来角色或损害退出能力？

### 常见误用

- 拿现实方案与理想化替代方案比较；
- 同时做 A 和 B，假装没有注意力成本；
- 只计算显性费用，不计算被占用的试错窗口；
- 用沉没成本为继续投入辩护。

## 三模型决策栈

```text
第一性原理：问题、事实、约束是什么？
→ 二阶思维：行动与不行动如何改变未来系统？
→ 机会成本：放弃的最佳替代是什么？
→ 概率世界观：在当前证据下，哪个选择的期望值更高且下行可承受？
→ 小实验：用最低成本获取下一条关键证据。
```
