# Layer 1：理解世界

> **组合命题：** 他人的行为不能只用性格或道德解释。先看博弈结构，再看信息分布与激励，最后判断哪些资源真稀缺。

## 模型 03：博弈论（Game Theory）

### 核心命题

你的最优策略取决于对方的策略、博弈次数、退出选项与未来价值，不是孤立存在的。

### 关键判断

| 维度 | 选项 | 决策含义 |
|---|---|---|
| 价值结构 | 零和 / 正和 / 负和 | 优先把可重构的零和变成正和；负和冲突尽快退出。 |
| 时间结构 | 单次 / 重复 | 重复博弈中，信誉、可预测性与修复能力比单次收益重要。 |
| 权力来源 | BATNA / 控制权 / 依赖度 | 没有退出选项时，口头公平无法抵消结构弱势。 |
| 承诺可信度 | 可逆 / 不可逆 | 承诺必须有成本或机制约束才可信。 |

重复博弈可采用 Tit for Tat 的四个原则：**先合作、受侵害后回应、对方修复后恢复合作、规则清晰。**

### 常见误用

- 把所有关系都理解成竞争；
- 只看当次分配，不看信誉和未来回合；
- 没有 BATNA 却试图靠话术获得权力；
- 用“长期合作”掩盖单边持续让利。

### 调用问题

```text
这是单次还是重复博弈？
双方的收益、成本、退出选项和不可逆投入是什么？
对方最优回应是什么？我的下一步会改变他的什么激励？
如何把价值结构从零和改成正和？
何时应修复，何时应退出？
```

## 模型 04：信息不对称（Information Asymmetry）

### 核心命题

交换双方掌握的信息不同，这个差异决定估值、风险与权力结构。

### 三类信息优势

1. **事实优势：** 知道对方不知道的数据、流程或约束。
2. **解释优势：** 能把分散信息组织成更准确的因果模型。
3. **执行优势：** 知道如何把信息转化为结果，且拥有真实 Outcome。

### 适用场景

- 对方低估你的资源或方案；
- 合作中存在隐藏信息、隐藏行动或代理问题；
- 用户表达、实际行为与结果数据不一致；
- 需要设计可信信号、验证机制或分阶段承诺。

### 常见误用

- 直接给高价值资源，却没先让对方看见其稀缺性与结果；
- 把“我知道得多”误判为“对方已经理解价值”；
- 以保密制造权力，却失去必要反馈与合作机会；
- 用信息优势操纵对方，破坏重复博弈中的信誉资产。

### 调用问题

```text
双方分别知道什么、不知道什么？
哪个关键事实导致估值差异？
怎样用低成本信号证明价值？
哪些信息可以公开，哪些执行配方与权重应保护？
如何通过试点、分段付款或 Outcome 降低信息风险？
```

## 模型 05：激励机制（Incentive Design）

### 核心命题

人的稳定行为主要由收益、成本、身份、地位和约束共同决定；口头意愿与道德叙事不能替代激励结构。

### 激励三层

- **物质激励：** 金钱、时间、风险、资源。
- **社会激励：** 地位、声誉、归属、面子。
- **身份激励：** 这个行为是否符合“我是谁”。

### 分析顺序

```text
看对方说什么
→ 看对方因为什么得益或受损
→ 看真实行为
→ 找到行为与激励一致之处
→ 修改结构，不劝意志
```

### 常见误用

- 用价值观教育解决结构性逆激励；
- KPI 奖励可量化指标，反而损害真实 Outcome；
- 只加奖励，不减少目标行为的摩擦与惩罚；
- 把解释机制等同于免除责任。

## 模型 06：稀缺性与丰盛性

### 核心命题

关键不是选择“稀缺思维”或“丰盛思维”，而是判断资源是否真的稀缺，以及分享是否会减少它。

| 资源 | 稀缺性 | 默认策略 |
|---|---|---|
| 时间、深度注意力 | 真稀缺 | 严格筛选 |
| 信任背书、个人信誉 | 真稀缺 | 高门槛、可追责 |
| 独特判断的权重与触发条件 | 真稀缺 | 选择性共享 |
| 普通行业信息与公开知识 | 低稀缺 | 主动分享，换取反馈与可见度 |
| “认识某个人” | 多数是伪稀缺 | 主动连接，成为网络节点 |
| 资源整合与调用能力 | 使用中增值 | 通过真实撮合积累信用 |

### 三层披露边界

```text
Layer 3 公开：事实、食材、通用知识
Layer 2 选择性交流：思路、框架、假设
Layer 1 保护：具体配方、权重、触发条件、未验证押注
```

### 常见误用

- 保护低价值信息，却免费消耗高价值注意力；
- 把所有分享都理解成损失，失去网络复利；
- 无差别公开核心判断与信任背书；
- 用“丰盛”合理化没有边界的给予。

## 四模型组合协议

面对合作、谈判和渠道问题时按顺序调用：

```text
博弈论：双方在玩什么游戏？
→ 信息不对称：谁知道什么，价值为何没被看见？
→ 激励机制：什么结构会稳定地产生当前行为？
→ 稀缺/丰盛：哪些资源该保护，哪些应通过分享增值？
```
