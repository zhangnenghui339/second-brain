# CareerRadar 决策原则（一页纸）

> 用法：做任何重要决策前，读一遍这页。就这样，没有别的流程。
> 更新：想改就直接改，Git 历史就是版本记录。

---

## 三条红线（碰到直接否决，不用讨论）

1. **不做"生成"类产品**——AI 让生成免费了，Builder/内容站打不过大厂免费额度。内容只是获客管道，不是资产。
2. **不做 auto-apply / 平台执行层的事**——那是 LinkedIn 的地盘，第三方必死。
3. **不砍 outcome 数据收集**——「这份简历有没有拿到面试」是唯一错过就补不回来的数据，任何决策与它冲突，它优先。

## 做决策前问自己四个问题

1. **这件事是在当裁判，还是在当运动员？**
   我们的位置是中立验证方。任何让我们"自己也卖简历工具"的事都会毁掉这个位置。

2. **如果 AI 引擎明天自己做了这个功能，我剩下什么？**
   剩下数据和方法论 → 可以做；什么都不剩 → 别做。

3. **这个东西是 Engine 还是 Payload？**
   通用能力（爬虫、pSEO、prompt、测试框架）写进 Engine 仓库，CareerRadar 死了它们还能用。CareerRadar 专属的东西认了，就是消耗品。

4. **在本周期预算内吗？**
   6 个月固定预算不突破，信号再好也不加注。

## 四个值得警觉的信号（看到了再回来翻这页）

- OpenAI / Perplexity 推出官方简历评测或工具排名 → 裁判位受威胁，考虑转型"给引擎供数据"
- Greenhouse / Lever 开放官方 parse API → "实测"不再稀缺，重心转向解读和 outcome 关联
- 大平台推出免简历的结构化 profile 直投 → 测试对象从 PDF 换成 profile，方法论不变
- AI 搜索引用越来越集中到大媒体 → 加码 email list，那是唯一没人能没收的渠道
