# CareerRadar 执行待办看板

> 记录 CareerRadar **执行层**的待办事项(具体、可勾选的任务),区别于 `strategy/`(战略方向选择)和 `decisions/`(重大决策记录)。相关物料统一存放在 [`materials/`](materials/)。
>
> **与根目录 `tasks/` 的边界**:根目录 `tasks/` 只放全局 if-then 决策规则型任务和月度 review,不放具体待办;本目录相反,只放 CareerRadar 项目的具体执行待办。两边不互相迁移。

## 归档规则

1. 已完成事项:状态改为 `已完成`,保留在表格中,不直接删除行(可追溯执行历史)
2. 任务需要展开详细说明(背景、步骤、验收标准)时,新建 `YYYY-MM-DD_任务名.md` 放在本目录下,并在表格"详情/物料"列链接过去
3. 任务相关的文档、截图、参考资料、链接本地副本等,统一放入 [`materials/`](materials/),并在表格"详情/物料"列链接过去
4. 单次新增/清理 >10 条待办时,先输出变更清单确认,再落盘
