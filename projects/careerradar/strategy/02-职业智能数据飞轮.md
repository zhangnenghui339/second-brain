# 方案 02：职业智能数据飞轮

## 主体定位

通过 Resume/JD 工具获得真实使用行为，连接用户修改前后差异和求职 Outcome，逐步形成 Career Intelligence，再用更强产品吸引更多用户和数据。

## 主体实现流程

```mermaid
flowchart LR
    A["Search Demand"] --> B["SEO / GEO 内容"]
    B --> C["Email / Account"]
    C --> D["Resume / JD 诊断"]
    D --> E["用户修改"]
    E --> F["再次测试"]
    F --> G["申请与 Outcome 回传"]
    G --> H["Career Intelligence<br/>岗位、简历、结果关联"]
    H --> I["Career Decision Engine"]
    I --> J["Personal Career Agent"]
    J --> D
```

## 系统组成

1. SEO/GEO：获得带明确职业需求的用户。
2. Resume/JD Diagnostic：形成第一批结构化行为数据。
3. 修改与再测：记录建议是否被采纳以及内容如何变化。
4. Outcome Pipeline：连接申请、拒绝、面试和 Offer。
5. Career Intelligence：建立岗位要求、用户能力、行动和结果之间的关联。
6. Decision Engine / Career Agent：将数据转回个性化决策产品。

## 核心特征

- 工具行为是数据入口。
- Outcome Data 是主复利资产。
- 产品价值从一次性生成升级为持续职业决策。
- Career Agent 是数据闭环成熟后的产品形态，不是冷启动入口。
