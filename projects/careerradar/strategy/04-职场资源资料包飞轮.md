# 方案 04：职场资源资产库飞轮

## 主体定位

构建求职领域的 GitHub + Wirecutter：把分散在论坛、职业档案和真实沟通案例中的非结构化材料，转化为可以搜索、复用和购买的结构化数字资产。

## 主体实现流程

```mermaid
flowchart LR
    A["Search Demand Radar"] --> B["确定角色 / 公司 / 场景"]
    B --> C["多源内容采集"]
    C --> D["LLM 结构化提取"]
    D --> E["人工精审与战术批注"]
    E --> F["Interview / Resume / Email 资产库"]
    F --> G["pSEO 资产页"]
    G --> H["搜索流量"]
    H --> I["局部预览 + Lead Capture"]
    I --> J["意图标签与 Newsletter"]
    J --> K["Affiliate / 付费资料包 / 资产订阅"]
    K --> B
```

## 三类主体资产

### Interview Questions Vault

采集 Reddit、Blind、Glassdoor 等面经，结构化为公司、岗位、题型、时间和 STAR 回答框架。

### Resume Bullet Points

将真实职业档案抽象成带量化 Placeholder 和行业词汇的句型骨架，并按 Role/Sub-category 形成 pSEO 页面。

### Email Templates

整理 Cold Email、内推、Follow-up 和谈薪模板，附带使用场景、心理机制和战术批注。

## 核心特征

- 结构化资源生产是第一推动力。
- 资产库本身同时承担内容、产品和 pSEO 数据源。
- LLM 负责规模化结构化，人工精审负责可信度和场景深度。
- 主要变现对象是拿来即用的数字资产，而不是黑箱算法。
