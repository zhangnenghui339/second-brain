# 职场资产云 (The Career Asset Vault) 战略全景图

## 1. 战略定位
- **定位**
  - 求职领域的 GitHub + Wirecutter 混合体
  - 放弃“技术硬核”实测壁垒，构建“场景化资产”规模壁垒
- **核心逻辑**
  - 不卖算法，不卖黑箱
  - 只卖确定性、拿来即用的高价值数字资产（JSON / Markdown）

## 2. 三大“复利资产”库

### 面试真题资产库：Interview Questions Vault
- **定位**: 极细分场景下的真实真题与 STAR 标准回答逻辑
- **数据源**: Reddit、Blind、Glassdoor 等论坛的非结构化面经
- **防 AI 替代壁垒**: 带有高频异动、时效性与特定公司业务深度绑定的高密度真题
- **生产线**: 爬虫抓取 ➔ LLM 结构化提取 ➔ 人工精审分类 ➔ 高级 LLM 补充 STAR 回答框架

### 简历成果句型资产库：Resume Bullet Points
- **定位**: 预留量化指标槽位（Placeholder）、带硬核行业词汇的工业级模具
- **防 AI 替代壁垒**: 拒绝 AI 假大空废话，提供语法骨架
- **pSEO 引擎**: `/resumes/[role]/[sub-category]` 
- **生产线**: 收集 LinkedIn 大厂精英 Profile ➔ LLM 抽象模板化并保留槽位 ➔ 自动分类入库 D1

### 求职沟通模板资产库：Email Templates
- **定位**: 覆盖求职全链路沟通（Cold Email、内推、Follow-up、谈薪）
- **防 AI 替代壁垒**: 核心壁垒在于附带的“心理学拆解”与“战术红字批注”
- **生产线**: 收集顶级个人实战模板 ➔ 人工深度精校与战术批注 ➔ 打包为 Notion 复制面板

## 3. 运行飞轮 (V8 优化版漏斗)
- [Search Demand Radar] 发现最近高频搜索词
- [pSEO + 资产页] 自动批量建页，截获精准长尾流量
- [高精度 Lead Capture] 局部模糊，用 PDF/Notion 模板换取 Email
- [Tag & Segment] 数据库根据行为打上意图标签
- [Nurture via Newsletter] 每周精准推送硬核干货资料
- [Monetization] L1 变现 (Affiliate) / L2 变现 (终极资料包)
