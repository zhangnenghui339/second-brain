# 候选路径：职业资产库 × 免费检索 × Newsletter 付费分发

> **备选，非决策。** 尚未进入「全部过门后再动手」；不得当作默认执行路线，不得写入 decisions/。

## 一层定位

| 层 | 角色 |
|---|---|
| CareerRadar / 飞轮 04 | 职业资产库（获客钩子 + 付费标的） |
| Newsletter / 飞轮 01 | 分发层与资产沉淀（Email List） |
| 免费内容 | 检索入口（完整可用，建立信任） |
| 付费层 | 卖节省时间、结构化、持续更新（archive + 模板/资源库存量，不只新内容） |

MVP 切割线抄 Interview Query：题免费 / 答案付费 → 订阅带资产属性，退订有损失感。参照：从零抄 IQ；Pragmatic Engineer 仅作列表 5,000+ 后的形态参照。

## 为何进候选（九门粗检）

竞品侧目前唯一看到「门 1（有人赚钱）+ 门 2（真实支付墙）」同时被他人跑通的方向；其余门（零平台依赖 / 数字秒交付 / 复利 / pSEO 获客等）逻辑上全绿，Solo 适配度高。正式过门与动手仍以 [`../决策原则_红线与MVP反脆弱九门.md`](../决策原则_红线与MVP反脆弱九门.md) 为准。

ATS 三 case 长文归入本体系的**引流内容**，不作独立商业项目。

## 半年三条错开收入曲线

| 阶段 | 收入 | 关键动作 |
|---|---|---|
| M1–M2 | Affiliate（compare/ silo） | 解 Impact.com 限制；上线 10–15 个 head-to-head 对比页 |
| M2–M4 | 一次性资源包 $19–49 | 免费资源做 lead magnet → 首个付费转化点 |
| M4–M6 | Newsletter paywall | 免费版建信任 → 付费档解锁 archive + 深度内容 |

**纪律：M1 不上 paywall。** 顺序：资源钩子 → 列表资产 → paywall 最后一层。

## Email 三层（按执行力节奏）

| 组件 | 启动 | 性质 |
|---|---|---|
| Email capture | Day 1，无条件 | Class A；每页可收 |
| 自动 drip | 写一次，永久跑 | 状态差的周的系统兜底 |
| 每周刊 | Day 60 支付门过 + 列表 300–500 后 | 唯一持续人工投入，最后再背 |

每周最低可交付单元 = 1 篇对比页 **或** 1 期 newsletter；状态好超额，状态差靠 pSEO 管道 + 自动发信。

## 结构抄法（待优化）

- 切割线：IQ「题 vs 答案」；PE「频率+深度」——资源库对齐前者。
- Paywall 机制可抄 Status：工作日进墙、周末免费开放。
- 平台倾向 beehiiv（capture + Stripe + 门控）；微信公众号仅国内引流入口。

## 参照产品：网址与核心价值

对照时带着两个问题看每个站：**切割线在哪**（免费→付费的墙砌在页面哪个位置）；**锁的存量是什么**。这两点是三家落地页设计的核心，也是自己落地页要回答的同样两个问题。

| 产品 | 主站 | 值得重点研究的页面 |
|---|---|---|
| Interview Query | https://www.interviewquery.com | 定价页 https://www.interviewquery.com/pricing（三档 + Lifetime）；点开任意一道题看「题免费 / 答案付费」如何在页内实现 |
| The Pragmatic Engineer | https://newsletter.pragmaticengineer.com | 免费/付费文章排布（每月 1 篇全文免费）；About 页看对付费层「存档 + 模板库」的承诺措辞。老博客 https://blog.pragmaticengineer.com 是约 9,000 冷启动订阅来源，看内容与 newsletter 的关系 |
| Lenny's Newsletter | https://www.lennysnewsletter.com | Product Pass https://www.lennysnewsletter.com/p/productpass（bundle 机制原文）；订阅页看 $15/mo、年付、「I Can Expense It」三档文案 |

### 一句话核心价值

| 产品 | 卖什么 |
|---|---|
| Interview Query | 把散落面经收敛成「公司 × 岗位」索引的结构化题库；卖面试前最后两周「不用自己拼答案」的时间 |
| Pragmatic Engineer | 行业内部资深工程师替你做全行业深度调研与判断；卖「用 $15/月订阅一个可信赖的行业大脑」 |
| Lenny's Newsletter | 把产品人成长所需的知识、人脉（社区）和工具（bundle）打包成会员卡；卖「进入这个圈层的门票」 |

**共同母题：** 用户付费买的不是信息本身（信息免费满地都是），而是「已经替你筛选、结构化、验证过」这道工序。本路径「付费层卖节省时间、结构化和持续更新」即该母题的抽象。

## 候选观察门（非正式 Kill，供回头优化）
