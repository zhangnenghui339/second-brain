# 邮件 1｜不要复制爆款，复制供需失衡

**Subject：** Seena Rez 真正值得复制的，不是短视频  
**Preheader：** 产品可以不同，商机发现的底层结构相同。

Seena Rez 的公开打法可以压缩成一条链：

```text
趋势扫描
→ YouTube / 社交内容转录
→ 提取反复出现的产品、抱怨与身份表达
→ 寻找供需缺口
→ 设计产品与品牌定位
→ 短视频获得流量
→ Retargeting 完成转化
```

大多数人会复制最后三步：做消费品、拍短视频、投 Retargeting。

但真正有价值的是前三步：

> 把分散、非结构化的需求表达，转成可验证的供需缺口。

对工具型创始人，这条链应该改写为：

```text
趋势 / 技术 / 监管 / 平台变化扫描
→ 搜索词、软件评论、工作流、招聘与采购数据采集
→ 提取重复任务、失败成本、人工预算与现有替代方案
→ 定位结构性供需缺口
→ 设计 Tool / Benchmark / Monitor / Agent Offer
→ SEO、pSEO、免费工具、行业研究或渠道合作获客
→ Email、SEM Retargeting 与 Demo 完成转化
```

这里没有要求创始人每天拍视频、维持人设或理解某种消费文化。

可信度来自：

- 数据是否可靠
- 工作流是否真正缩短
- 结果是否可复现
- 用户能否自己验证价值

这更符合“离机器近、离文化远”的 Founder Fit。

短视频不是商业模式，只是一种分发介质。对一个不适合持续人格在场的创始人，强行复制短视频 DTC，等于复制了别人的优势和自己的摩擦。

真正应该复制的是：

```text
发现供需失衡
→ 做出最小 Offer
→ 让真实支付纠错
→ 把重复交付固化为数据、软件与分发资产
```

**本封行动：** 以后看到一个成功案例，只拆三个问题：

1. 它发现了什么供需失衡？
2. 它的获客优势来自哪里？
3. 去掉创始人人格后，这个系统还能不能运行？
